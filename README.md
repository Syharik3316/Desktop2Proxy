# 🤖 Артеллерийское точное подключение 42x САУ

Кроссплатформенный инструмент для определения удаленного хоста, анализа операционной системы и подключения к различным сервисам.
Видео-демонстрация работы: https://rutube.ru/video/c35c5849946e8e3f0595df363dac9fbc/

## 🚀 Возможности

- **Определение ОС** по TTL, баннерам сервисов и открытым портам
- **Сканирование портов** с поддержкой многопоточности
- **Автоматическое подключение** к различным сервисам:
  - HTTP/HTTPS веб-интерфейсы
  - SSH подключения
  - RDP (Remote Desktop)
  - VNC (Virtual Network Computing)
  - FTP серверы
  - Telnet подключения
  - MikroTik RouterOS
  - CISCO
- **Кроссплатформенность** - работает на Windows и Linux
- **Графический интерфейс** с удобным управлением
- **Кнопка отмены** для прерывания сканирования
- **Сохранение отчетов** о сканировании

## 📋 Требования

- Python 3.6 или выше
- Библиотеки Python (tkinter)
- Для Linux (sudo apt install xtightvncviewer freerdp2-x11)

## 📋 Принцип работы

Программа запросит IP адресс удалённого хоста, после начнёт проверку.
Программа проверит подключение через ping и начнёт проверку открытых портов.
После проверки, программа укажет к какой ОС относится удалённых хост и
подскажет каким образом подключаться.
Так-же программа за место пользователя запустит нужный метод подключения,
из-за чего пользователю останется только ввести логин + пароль.

## 🛠️ Установка и запуск

### Windows

1. Убедитесь, что Python установлен:
   ```cmd
   python --version
   ```

2. Запустите инструмент:
   ```cmd
   python desktop2proxy.py
   ```

3. При необходимости запустите графический интерфейс (Beta версия):
   ```cmd
   python run_gui.py
   ```
   Либо запуск start_gui.bat

### Linux

1. Убедитесь, что Python и tkinter установлены:
   ```bash
   python3 --version
   sudo apt install python3-tk  # для Ubuntu/Debian
   ```

2. Запустите инструмент:
   ```bash
   python3 desktop2proxy.py
   ```

3. При необходимости запустите графический интерфейс (Beta версия):
   ```bash
   python3 run_gui.py
   ```

## 📖 Использование

### Консольная версия

Для использования оригинального консольного интерфейса:

```cmd/bash
python desktop2proxy.py
python3 desktop2proxy.py
```

### Графический интерфейс

1. **Введите IP-адрес** целевого хоста в поле ввода
2. **Настройте параметры** сканирования (таймаут, количество потоков)
3. **Нажмите "Сканировать"** для начала анализа
4. **При необходимости нажмите "Отменить"** для прерывания сканирования
5. **Дождитесь завершения** сканирования
6. **Используйте кнопки подключения** для соединения с найденными сервисами

## 🖥️ Определение ОС

Программа определяет операционную систему по трем методам:

1. **TTL анализ** - анализ времени жизни пакетов
2. **Баннеры сервисов** - анализ ответов сервисов
3. **Анализ портов** - характерные порты для разных ОС

## 🐛 Устранение неполадок

### Проблемы с tkinter

**Windows**: tkinter обычно входит в стандартную установку Python

**Linux**: Установите tkinter:
```bash
# Ubuntu/Debian
sudo apt install python3-tk

# CentOS/RHEL
sudo yum install tkinter

# Arch Linux
sudo pacman -S tk
```

### Проблемы с правами доступа

Для некоторых операций (ping, сканирование портов) могут потребоваться права администратора:

**Windows**: Запустите командную строку от имени администратора

**Linux**: Используйте sudo:
```bash
sudo python3 gui_connection_manager.py
```
